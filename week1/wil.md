 첫 입문 스터디에서는 먼저 git 연동하는 방법을 배웠다. 맥에서는 홈브루를 설치하고 터미널을 이용해 git을 연동해 vscode로 작업한 작업물을 간단한 명령어로 올릴 수 있다. git add 로 파일을 추가하고 commit -m <메세지> 으로 커밋한 후 git push까지 해야지 작업한 프로젝트가 git에 동기화가 된다. html을 이용해 간단한 웹페이지를 만들었다. 문서양식을 통일시키는 것이다. 처음에 ! -> tap 하면 html 의 기본 양식이 나온다. <tag>내용</tag> 이런식으로 마크업하면 된다. tag에 따라 글자크기 등이 달라지는 것 같다. title tag에 내용을 넣으면 위에 이름이 바뀌고, h1~.. 는 제목에 관련된 tag 이고, p는 본문을 쓰는 tag이다.
